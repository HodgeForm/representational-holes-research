# Zenodo release plan — hold

Zenodo's GitHub integration archives GitHub releases from enabled public repositories; the current repository is private. Do not change visibility or publish a release until code, IP, author, and evidence review are complete.

Before release:
1. Verify and include exact experiment code, data, grammar, proof, and replay receipts.
2. Agree on license and citation metadata.
3. Remove private credentials and proprietary materials; review full Git history before making public.
4. Enable the public repository in Zenodo **before** creating the GitHub release.
5. Publish a versioned GitHub release; verify Zenodo archival and DOI.
6. Insert verified DOI and URL into Medium/X drafts before publishing.

Documentation: https://help.zenodo.org/docs/github/
