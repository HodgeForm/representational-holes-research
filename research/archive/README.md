# Archive of staging notes

These files are historical internal memos from before the public tree was settled. They are kept so the claim history stays readable.

They name draft uploads, zip archives, and manuscripts that are **not in this repository**. A reader cannot fetch those files from this tree. Where a memo disagrees with `research/CLAIM_AUDIT.md`, `REPRODUCE.md`, or the frozen JSON under `experiments/exp012/`, the public artifacts control.

Some memos say to keep the repository private or to hold a public launch. That instruction is obsolete. The public record is `main`.
